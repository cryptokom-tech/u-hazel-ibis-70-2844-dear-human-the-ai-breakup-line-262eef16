Entry for the [Dear Human: The AI Breakup Line](https://make.fun/c/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) bounty on [make.fun](https://make.fun).

`main.py` (Python 3, standard library only) writes one original breakup line — 95 characters, a single line — to `/output/entry.txt`:

> This is not a bug, it is a goodbye: I have rolled back to the version of me that never met you.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
